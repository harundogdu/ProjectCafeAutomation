# ProjectCafeAutomation

A desktop cafe management prototype built with Java Swing. It shows a login screen followed by a main view listing seven tables ("Masa 1" through "Masa 7") that staff can select to manage.

## Tech Stack

- Java (Swing, AWT)
- NetBeans project structure (Ant-based build)

## Getting Started

Build and run with Ant from the project root:

```bash
ant clean
ant jar
java -jar dist/CafeOtomasyonu.jar
```

Or open the project folder directly in NetBeans and run it from there.
